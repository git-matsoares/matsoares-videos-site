# Shorts de Matheus Soares

Lista pública de até 12 Shorts de https://www.youtube.com/@soumatsoares/shorts.

O site lê videos.json diretamente. A automação atualiza a lista a cada hora (minuto 17), sem FTP ou chave de API. Também pode ser executada manualmente em Actions. Falhas preservam a lista anterior. A coleta depende do formato da página pública do YouTube.

Para pausar, desative o workflow em Actions. O GitHub pode suspender agendamentos de repositórios públicos após 60 dias sem atividade; confira Actions se a lista parar de atualizar.
